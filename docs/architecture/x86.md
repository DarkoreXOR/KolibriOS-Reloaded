# x86 Architecture Layer

## CPU mode

**LOCAL FACT:** 32-bit protected mode kernel after boot. Starts in 16-bit real mode (`bootbios.inc`), enters PE, then enables paging.

No long mode / x86-64 in this kernel tree.

## Control registers

| Register | Usage | Evidence |
|----------|-------|----------|
| CR0 | PE, PG, WP, CD/NW (mem_test), TS (FPU lazy) | `bootbios.inc`, `kernel.asm`, `sched.inc`, upstream `mem_test` |
| CR2 | Page fault address | `#PF` path `memory.inc` |
| CR3 | Current `PROC.pdt_0` physical | `do_change_task`, paging enable |
| CR4 | PSE, PGE, OSFXSR/OSXSAVE as needed | `high_code`, FPU/AVX paths |
| EFLAGS | IF, AC/ID probes in `test_cpu` | upstream `init.inc` |

## GDT

**LOCAL FACT** — `gdts` in `data32.inc`. Selector order matters for SYSENTER/SYSCALL (kernel CS/SS, user CS/SS). Includes: `os_code`, `os_data`, `app_code`, `app_data`, PCI BIOS, APM, graphics, `tss0`, TLS.

Loaded: temporary GDT in real-mode switch; final `lgdt [gdts]` at paging enable and AP path.

## IDT

**LOCAL FACT:** Built by `build_interrupt_table` (`core/sys32.inc`) into `idts` at `0x8000B100`, then `lidt`.

- Vectors 0–0x1F: exceptions (`e0`–`e19`, `page_fault_exc`, …)
- IRQ vectors remapped (PIC comment: ints `0x20`–`0x2f`)
- Vector `0x40`: trap gate to `i40` (syscalls)

## TSS

**LOCAL FACT:** Single shared TSS at `0x805FFF80` (not hardware task switching). Fields used:

- `tss._esp0` — ring0 stack on privilege change
- I/O permission bitmaps (`tss._io_map_0/1`) remapped per thread

Loaded with `ltr tss0`.

## MSRs

**LOCAL FACT** (`kernel.asm` fast syscall init):

- Intel: `IA32_SYSENTER_CS/ESP/EIP` → `sysenter_entry`
- AMD: `EFER.SCE`, `STAR` → `syscall_entry` (STAR encoding includes user/kernel selectors)

## FPU / SSE / AVX

**LOCAL FACT:** `core/fpu.inc` — `#NM` handler, lazy FPU ownership via `CR0.TS`, save/restore; exports `FpuSave`/`FpuRestore`, AVX variants. Context switch may XSAVE and set TS when owner changes (`do_change_task`).

## Atomicity / barriers

**LOCAL FACT:** Uniprocessor-oriented. “Spinlocks” are `pushf/cli` / `popf` macros (`const.inc`). No real SMP spinlock semantics for `SchedulerLock`.

**UNKNOWN:** Full correctness of AP deep-sleep / STARTUP paths under concurrent mutation.

## Port I/O / CPUID / cache

Widely used (`in`/`out`, `cpuid` in `test_cpu`, `wbinvd` in mem_test, TLB via CR3 reload, INVLPG sites — search `memory.inc`).
